## Interface et thèmes

- Dashboard KIMIA V0.7 : accueil, sections Lumières, Volets, Climatisation, Musique, Sécurité, Prises, Paramètres et plan Maquette.
- Quatre thèmes : Gris Premium, Clair, Sombre, Signature.
- Correctif contraste des menus déroulants validé en VM pour Gris Premium et Sombre, après redémarrage.
- Les anciennes entités privées de la maison témoin (clims, Netatmo, gestion automatique, consigne) ont été remplacées par des **emplacements inactifs à associer**.
- La météo de l'accueil a été repensée avec un bandeau premium, température actuelle et prévisions.
- **Dernier changement GitHub de la soirée** : couleurs météo locales (soleil, nuages, pluie, lune). Le rendu final de cette modification n'a **pas encore été confirmé** dans la VM après import.

- Intégration Met.no configurée pour Libreville, Gabon.

## Actualités RSS

Quatre capteurs présents dans la VM, confirmés dans Home Assistant :
- `sensor.rss_gabon_actu` — Gabon Actu ;
- `sensor.rss_gabonreview` — GabonReview ;
- `sensor.rss_rfi_afrique` — RFI Afrique ;
- `sensor.rss_france_24` — France 24.

Fichiers sources **sauvegardés dans ce dépôt** :
- `kimia/rss_reader.py` : parseur RSS/Atom Python standard ;
- `packages/kimia_rss_sources.yaml` : quatre capteurs `command_line`, actualisation toutes les 30 min.

À installer dans Home Assistant : `/config/kimia/rss_reader.py` et `/config/packages/kimia_rss_sources.yaml`.
Le fichier historique `packages/kimia_rss_optional.yaml` décrit un **autre système (Feedreader)** et n'est pas nécessaire ici.
Les actualités dépendent d'Internet et de la disponibilité des éditeurs ; confirmer les conditions de réutilisation commerciale avant livraison.
